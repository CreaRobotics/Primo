# PRIMO Digital Twin

[Read in Italian](README.md)

This folder contains the digital twin of PRIMO, a virtual replica of the manipulator that can be used with **RoboDK**. It lets you test the robot's movements and study its behavior before connecting it to real hardware.

## Try Primo-1.2 online

No installation is required: you can open the simulation directly in your browser with **RoboDK for Web**:

**[Open the PRIMO simulation (Pick and Place)](https://web.robodk.com/lnk/3132343231233832)**

The simulation is a *pick and place* example, in which the manipulator picks up and moves an object. You can use it to:

- see how PRIMO moves through a complete work cycle;
- understand how the joints and the spherical wrist work together;
- experiment with motion changes before applying them to the real robot.

## Folder contents

The digital twin is designed to be opened with RoboDK locally, where you can modify the scene, the paths, and the robot parameters. For assembly and configuration instructions for the real robot, see the [official PRIMO manual](https://crearobotics.github.io/PRIMO-Docs/cos_e_la_robotica/).
