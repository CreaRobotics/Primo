# PRIMO Operating System

This folder contains the operating system for Raspberry Pi with the tools and configurations preinstalled for PRIMO. Once installed on the Raspberry Pi, the robot is ready to be configured and controlled without preparing the software from scratch.

## Request or send the image and configurations

If you need the operating system image, PRIMO's configurations, or you want to send us your own changes, write to:

📧 **[info@crearobotics.com](mailto:info@crearobotics.com)**

Please mention the PRIMO version you are using in your email, so we can help you more quickly.

## Need help?

For questions about installation or configuration, you can also ask on our [Discord server](https://discord.com/invite/ezhwUz77eK), where the community can offer quick support.
