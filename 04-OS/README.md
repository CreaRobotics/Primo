# Sistema operativo PRIMO

Questa cartella contiene il sistema operativo per Raspberry Pi con gli strumenti e le configurazioni preinstallati per PRIMO. Installandolo sul Raspberry Pi, il robot è pronto per essere configurato e controllato senza dover preparare il software da zero.

## Richiedere o inviare l'immagine e le configurazioni

Se hai bisogno dell'immagine del sistema operativo, delle configurazioni di PRIMO o se vuoi inviarci le tue modifiche, scrivi a:

📧 **[info@crearobotics.com](mailto:info@crearobotics.com)**

Indicando nella mail la versione di PRIMO che utilizzi, potremo aiutarti più rapidamente.

## Serve aiuto?

Per domande sull'installazione o sulla configurazione puoi anche chiedere sul nostro [server Discord](https://discord.com/invite/ezhwUz77eK), dove la community può offrire un supporto rapido.
